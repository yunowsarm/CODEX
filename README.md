# 图片 + 压缩包 双格式文件生成器

桌面端应用：选择存储位置、图片和压缩包后，在本地拼接二进制数据，生成既可当图片查看、也可当 ZIP 解压的复合文件，并直接保存到所选文件夹。

## 运行方式

```bash
npm install
npm start
```

## 使用步骤

1. **选择文件存储位置**：点击「选择文件夹」，选定生成文件的保存目录（会记住上次选择）。
2. **选择图片文件**：建议 JPG，选后可预览。
3. **选择压缩包文件**：选择要合并的 ZIP 等文件。
4. 点击「生成」：复合文件会保存到步骤 1 所选文件夹，并弹出「图片已保存」提示。
5. 可点击「打开生成文件夹」直接打开保存目录；「重置」会清空图片与压缩包选择，但不会清除存储位置。

## 打包成 exe（Windows）

```bash
npm run build
```

安装包输出在 `dist/` 目录。若只需免安装的绿色版：

```bash
npm run build:dir
```

运行后使用 `dist/win-unpacked/` 内的 exe。

## 原理

- 数据顺序：图片在前，压缩包在后 → `[图片字节][ZIP 字节]`。
- 图片查看器通常只解析到图片结束，尾部数据被忽略，故可正常显示。
- ZIP 解压从文件尾定位目录，前部图片数据一般不影响解压。

## 注意

- 需在 **Electron 环境**下运行（`npm start` 或打包后的 exe），才能选择存储位置并保存到本地。
- 兼容性取决于具体查看器/解压器，建议在目标环境中测试。
- 所有操作在本地完成，不会上传任何文件。
