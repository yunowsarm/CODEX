# 图片 + ZIP 双格式文件生成器

一个纯前端工具：选择图片和 ZIP 后，在浏览器本地拼接二进制数据，生成可作为图片查看、也可作为 ZIP 解压的复合文件。

## 使用方式

1. 打开 `index.html`。
2. 选择图片文件（建议 JPG）。
3. 选择 ZIP 文件。
4. 点击“生成复合文件”。
5. 可下载为图片后缀版本或 `.zip` 版本。

## 原理

- 图片在前，ZIP 在后：`[image bytes][zip bytes]`
- 多数图片解码器会忽略尾部冗余数据，因此图片可正常显示。
- ZIP 解压器从文件尾定位目录结构，因此前部图片数据通常不影响解压。

## 注意

- 兼容性取决于具体查看器/解压器，建议在目标环境中测试。
- 本工具不会上传文件，所有操作在浏览器本地完成。
